# ABSOLUTE #1

1. Upload all these files to a GitHub repo (keep the `.github` folder).
2. Go to **Actions → Build APK → Run workflow**.
3. When it finishes, download **ABSOLUTE-1-apk** from the run's Artifacts and unzip it to get `app-debug.apk`.

App icon: `android-res/` (generated from your picture). App code: `www/index.html`.
